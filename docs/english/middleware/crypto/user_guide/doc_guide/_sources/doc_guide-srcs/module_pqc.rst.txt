################################################################################
Post Quantum Cryptography Module
################################################################################

The post quantum cryptography (PQC) module provides asymmetric cryptography
(for example, digital signatures and key encapsulation mechanisms) which is
more resiliant in the face of an adversary in possession of cryptographically
relevant quantum computation capability, in addition to classical computation
capability.
