################################################################################
Performance and Throughput - MSPM0G Platform
################################################################################

The performance and throughput of various primitives suppored by this library is
given here for reference.

The target device used for testing is the MSPM0G3519 device.

**NOTE:** Some primitives are deterministic in execution time.  Others may be
non-deterministic, and the application needs to consider if this is an issue or
not during integration.  As an example, hash functions generally execute in
deterministic time for a given message size, excluding any cache hit/miss
implications.  Other functions, such as the PQC ML-DSA sign operation, do not
execute in determinstic time by construct (in this case, due to the rejection
sampling process of ML-DSA).

********************************************************************************
RSA: Digital Signature Verification
********************************************************************************

The average RSA performance for MSPM0G is given in the table for 80MHz 
(2 flash wait states) operation.  For RSA, the full verify function
does the combined work of preparing the key (key prep) and performing the
verification computations.  The fast verify does not perform the key preparation
and rather assumes this was done in advance.  The key preparation may be done
in advance for each supported public key, at the expense of additional flash
memory space used to store the key parameters.  The benefit of precomputation
is the reduction in total verification time of ~50%.

+--------------+-------------+----------+---------------+---------------+
| Algorithm    | Function    | CPUCLK   | kcycles (avg) | Seconds (avg) |
+==============+=============+==========+===============+===============+
| RSA-2048     | Key prep    | 80000000 | 15398         | 0.192         |
+--------------+-------------+----------+---------------+---------------+
| RSA-2048 PSS | Fast verify | 80000000 | 15368         | 0.192         |
+--------------+-------------+----------+---------------+---------------+
| RSA-2048 PSS | Full verify | 80000000 | 30766         | 0.385         |
+--------------+-------------+----------+---------------+---------------+
