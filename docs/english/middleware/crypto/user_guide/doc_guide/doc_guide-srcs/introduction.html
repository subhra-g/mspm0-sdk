1. MSP Crypto Library Introduction¶

The MSP Crypto Library is a comprehensive cryptography library designed for TI microcontroller products, particularly the MSPM0 and MSPM33 families of MCUs.

1.1. Key Features¶

The library includes the cryptographic modules given in the table below.

1.2. Additional Information¶

This library provides a range of cryptographic modules with hardware acceleration used where applicable, falling back to software implementations otherwise.

1.2.1. Library Structure¶

The library is delivered pre-built and is intended to be used without recompilation. Source code is provided for certain modules to offer transparency on implementations.

1.2.3. Hardware Cryptography Module Support¶

The library can leverage hardware crypto modules on compatible devices:

  • AESADV module for AES operations

  • TRNG module for true random number generation

  • PKA module for elliptic curve operations

1.3. Project Configuration¶

When using the provided example projects, the projects are pre-configured for using the MSP-CRYPTO-LIB.

When including the MSP-CRYPTO-LIB into a custom project (not an example), the following project build configuration settings must be applied:

  1. Add the include path of the library to the project build configuration. The include path of the library is <INSTALL_DIR>/source where <INSTALL_DIR> is the root install directory of the MSP-CRYPTO-LIB.

  2. Within the project source file(s) which will use MSP-CRYPTO-LIB, add the include statement for the top level library header file msp-crypto-lib.h by adding #include “ti/crypto/include/msp-crypto-lib.h” to the list of header file includes. This top level header file includes all of the module header files in MSP-CRYPTO-LIB.

  3. Add the library for the target hardware to the linker library list. As an example, for the MSPM0G3519 device, one would add the following to the linker build options: -l<INSTALL_DIR>/source/ti/crypto/lib/ticlang/m0p/mspm0gx51x/cryptolib.a

  4. Add the MSP-CRYPTO-LIB configuration definitions to the compiler build options. As an example, for the MSPM0G3519 device, one would add the following to the compiler build options: -DCRYPTO_HW_USE_MSPM0_AESADV=1, -DCRYPTO_HW_USE_MSPM0_TRNG=1, and -DCRYPTO_EC_WIN=3.
