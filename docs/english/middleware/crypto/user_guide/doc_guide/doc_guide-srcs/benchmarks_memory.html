9.3. Memory Requirements¶

The memory requirements for various modules of the library are given below as a reference for estimating the memory impact of including a given primitive.

NOTE: Some primitives share subroutines. In these cases, the code (flash) size for including two algorithms (for example, a sign and verify algorithm) may be lower than the simple sum of the code size of each algorithm on its own.

NOTE: Some primitives require a minimum stack space to be available. Be sure to budget the stack usage for your application, considering call sequences.

NOTE: This library does not use any dynamic memory allocation (no heap). All SRAM memory required by the library is taken from the call stack itself.
