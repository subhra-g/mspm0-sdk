9.2. Performance and Throughput - MSPM33C3 Platform¶

The performance and throughput of various primitives suppored by this library is given here for reference.

The target device used for testing is the MSPM33C321A device.

NOTE: The following device configurations were tested:

  • 32MHz

    • Flash cache: OFF

    • Flash wait states: 0

    • SRAM wait states: 0

  • 80MHz

    • Flash cache: ON

    • Flash wait states: 1

    • SRAM wait states: 0

  • 160MHz

    • Flash cache: ON

    • Flash wait states: 2

    • SRAM wait states: 1

NOTE: Some primitives are deterministic in execution time. Others may be non-deterministic, and the application needs to consider if this is an issue or not during integration. As an example, hash functions generally execute in deterministic time for a given message size, excluding any cache hit/miss implications. Other functions, such as the PQC ML-DSA sign operation, do not execute in determinstic time by construct (in this case, due to the rejection sampling process of ML-DSA).
