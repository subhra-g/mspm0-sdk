Detailed Description

Runtime state for a single filterbank feature extraction instance.

Holds all mutable state required to operate the filterbank pipeline: the active configuration, pointers to library-owned internal buffers, sample-packing staging arrays, processing index counters, and the caller-supplied output feature window.

Callers must allocate an instance of this structure (stack or static) and pass it to FBFE_Init() before using any other API function. The structure should be treated as opaque after initialization; direct field access is not part of the public API contract.

Copy of the configuration supplied to FBFE_Init().

Stored by value so the caller is free to discard or reuse the original FBFE_Config after initialization returns.

Referenced by FBFE_Init(), FBFE_PushSample(), and FBFE_StoreSampleBytes().

§ final_features

uint8_t* FBFE_Ctx::final_features

Pointer to the caller-supplied sliding feature window buffer.

Updated by FBFE_RunOneFrame() after every frame. The buffer must remain valid for the lifetime of the context. Its required size is at least FEATURES_BYTES bytes.

Referenced by FBFE_ClearInternalBuffers(), FBFE_Init(), and FBFE_ShiftNNInputWindow().

§ final_features_bytes

size_t FBFE_Ctx::final_features_bytes

Size in bytes of the final_features buffer.

Captured at initialization and used to guard against buffer overruns when clearing or updating the feature window.

Referenced by FBFE_Init().

§ sample_index

uint16_t FBFE_Ctx::sample_index

Index of the next sample slot within the current frame.

Counts from 0 to NUM_SAMPLES - 1, wrapping back to 0 once a full frame has been accumulated. Updated by FBFE_PushSample().

Referenced by FBFE_AdvanceSampleState(), FBFE_Init(), FBFE_PackFourSamplesIntoFrameBuffer(), and FBFE_UpdateInputBufferAtFrameEnd().

§ pack_index

uint8_t FBFE_Ctx::pack_index

Index into the four-sample packing group (0–3).

Tracks which position within the current group of four samples is being filled. When it reaches 3, the four staged bytes are flushed to frame_buffer by FBFE_PackFourSamplesIntoFrameBuffer().

Referenced by FBFE_AdvanceSampleState(), FBFE_Init(), FBFE_PushSample(), and FBFE_StoreSampleBytes().

uint8_t FBFE_Ctx::ms_bytes[4]

Staging array for the most-significant bytes of up to four samples.

Holds the MS byte extracted (after masking and shifting) from each of the four samples in the current packing group, indexed by pack_index.

Referenced by FBFE_PackFourSamplesIntoFrameBuffer(), and FBFE_StoreSampleBytes().

§ frame_buffer

int16_t* FBFE_Ctx::frame_buffer

Pointer to the raw packed-word frame buffer (library-owned).

Bound to the internal static array g_frame_buffer during FBFE_Init(). Stores one complete frame of packed int16_t words ready to be copied into fb_input at frame boundaries. Capacity: NUM_SAMPLES elements.

Referenced by FBFE_BindInternalBuffers(), FBFE_ClearInternalBuffers(), FBFE_PackFourSamplesIntoFrameBuffer(), and FBFE_UpdateInputBufferAtFrameEnd().

§ fb_input

int8_t* FBFE_Ctx::fb_input

Pointer to the overlapped NPU input buffer (library-owned).

Bound to the internal static array g_fb_input during FBFE_Init(). Holds the packed byte stream for the NPU, including the overlap region from the previous frame. Capacity: FB_INPUT_BYTES bytes.

Referenced by FBFE_BindInternalBuffers(), FBFE_ClearInternalBuffers(), FBFE_RunOneFrame(), and FBFE_UpdateInputBufferAtFrameEnd().

§ msb_temp

int32_t* FBFE_Ctx::msb_temp

Pointer to the MSB-pass output scratch buffer (library-owned).

Bound to g_msbTemp during FBFE_Init(). Receives the sign-extended DREG19 results of the MSB pass for one stride before they are combined with the LSB results. Capacity: MODEL_MAX_OUT_CH_PER_ITER elements.

Referenced by FBFE_BindInternalBuffers(), FBFE_RunOneFrame(), and FBFE_UpdateMaxValuesForStride().

§ lsb_temp

int32_t* FBFE_Ctx::lsb_temp

Pointer to the LSB-pass output scratch buffer (library-owned).

Bound to g_lsbTemp during FBFE_Init(). Receives the sign-extended DREG19 results of the LSB pass for one stride before combination and maxpool update. Capacity: MODEL_MAX_OUT_CH_PER_ITER elements.

Referenced by FBFE_BindInternalBuffers(), FBFE_RunOneFrame(), and FBFE_UpdateMaxValuesForStride().

§ max_values

int32_t* FBFE_Ctx::max_values

Pointer to the per-channel maximum accumulator (library-owned).

Bound to g_maxValues during FBFE_Init(). Tracks the highest combined MSB+LSB activation seen across all stride positions for every output channel within a single frame. Capacity: MODEL_CONV_OUT_CHANNELS elements.

Referenced by FBFE_BindInternalBuffers(), FBFE_ClearInternalBuffers(), FBFE_InitBlockMaxValues(), FBFE_PostprocessBlock(), and FBFE_UpdateMaxValuesForStride().

§ single_out

uint8_t* FBFE_Ctx::single_out

Pointer to the single-pass NPU output buffer (library-owned).

Bound to g_singleOut during FBFE_Init(). Configured as the OFMAP destination in the NPU's CTL1 register for each pass. Capacity: MODEL_CONV_OUT_CHANNELS bytes.

Referenced by FBFE_BindInternalBuffers(), FBFE_ClearInternalBuffers(), and FBFE_RunOneFrame().

§ maxpool_outputs

uint8_t* FBFE_Ctx::maxpool_outputs

Pointer to the quantized maxpool output buffer (library-owned).

Bound to g_maxpool during FBFE_Init(). Receives the final uint8_t feature values produced by FBFE_PostprocessBlock() and is passed to FBFE_ShiftNNInputWindow() to update the feature window. Capacity: MODEL_CONV_OUT_CHANNELS bytes.

Referenced by FBFE_BindInternalBuffers(), FBFE_ClearInternalBuffers(), FBFE_PostprocessBlock(), and FBFE_RunOneFrame().

§ inited

bool FBFE_Ctx::inited

Initialization guard flag.

Set to true by FBFE_Init() upon successful completion. All API functions check this flag via FBFE_IsReady() and return false immediately if it is not set.

Referenced by FBFE_Init(), and FBFE_IsReady().
