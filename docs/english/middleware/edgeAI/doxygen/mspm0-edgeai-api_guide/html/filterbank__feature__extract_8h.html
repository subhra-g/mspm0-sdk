filterbank_feature_extract.h File Reference

Detailed Description

Filterbank Feature Extraction — public API and types.

This module implements filterbank-based feature extraction for keyword detection and similar machine-learning inference workloads. It provides an efficient pipeline that:

  • accepts a continuous stream of signed 16-bit PCM audio samples,
  • packs and overlaps frames into the format expected by the NPU,
  • runs MSB and LSB weight passes on the NPU hardware accelerator,
  • applies maxpool, scale, offset, and quantization post-processing, and
  • maintains a sliding feature window for the downstream classifier.

Typical usage sequence:

FBFE_Config cfg = { ... };
FBFE_Ctx ctx;
uint8_t features[FEATURES_BYTES];
FBFE_Init(&ctx, &cfg, features, sizeof(features));
while (audio_available())
{
FBFE_PushSample(&ctx, get_next_sample());
}
if (frame_complete())
{
FBFE_RunOneFrame(&ctx);
// features[] now contains the updated sliding window
}

#include <stddef.h>
#include <stdbool.h>
#include "fe_model/model_autogen.h"

Initialize a filterbank feature extraction context.

Validates all arguments, zeros the context structure, copies the configuration, binds the library-owned internal buffers, clears every buffer to a deterministic all-zero state, and marks the context as ready.

This function must be called exactly once before any other API function operates on ctx. Calling it a second time on an already-initialized context is safe and resets the pipeline to its initial state.

Parameters
[in,out]ctxPointer to the caller-allocated context structure to initialize. Must not be NULL.
[in]cfgPointer to the configuration to apply. Copied by value; the caller may free or reuse it after this call returns. Must not be NULL.
[in]final_featuresPointer to the caller-supplied buffer that will hold the sliding feature window. Must remain valid for the lifetime of ctx. Must not be NULL.
[in]final_features_bytesSize in bytes of final_features. Must be at least FEATURES_BYTES.
Returns
true if the context was successfully initialized.
false if any pointer argument is NULL or if final_features_bytes < FEATURES_BYTES.

Push one signed 16-bit PCM sample into the processing pipeline.

Scales the sample according to the configured FBFE_Config::branch_bits, splits it into MSB and LSB byte components, and stages them in the internal packing arrays. Every fourth call flushes the staged bytes into the frame buffer in the interleaved layout required by the NPU. When the last sample of a complete frame is received (sample_index == NUM_SAMPLES - 1), the NPU input buffer is updated by sliding the overlap region forward and appending the new frame.

Callers must push exactly NUM_SAMPLES samples between consecutive calls to FBFE_RunOneFrame() to keep the pipeline in sync.

Parameters
[in,out]ctxPointer to an initialized context. Must not be NULL.
[in]sampleSigned 16-bit PCM audio sample to push.
Returns
true if the sample was accepted and processed.
false if ctx is NULL or has not been initialized.

Push one signed 16-bit PCM sample into the processing pipeline.

§ FBFE_RunOneFrame()

bool FBFE_RunOneFrame ( FBFE_Ctx *  ctx)

Run the filterbank NPU pipeline on the current input frame.

Executes the complete feature extraction sequence for one frame:

  1. Computes NPU addressing registers from the current buffer pointers.
  2. Iterates over MODEL_NUM_OUTPUT_BLOCKS output channel blocks.
  3. For each block: loads MMR coefficients, programs common NPU state, loads the instruction stream (first block only), and loads the block-specific weight parameters.
  4. For each of MAX_FB_STRIDE_ITER stride positions: runs an MSB pass followed by an LSB pass, combines their outputs, and updates the per-channel maximum accumulator.
  5. Applies scale, offset, right-shift, and uint8_t clamping to each channel's accumulated maximum value.
  6. Appends the resulting quantized feature vector to the sliding NN input window in FBFE_Ctx::final_features.

This function should be called once per frame, after NUM_SAMPLES samples have been pushed via FBFE_PushSample().

Parameters
[in,out]ctxPointer to an initialized context. Must not be NULL.
Returns
true if the frame was processed successfully.
false if ctx is NULL, has not been initialized, or if a weight-parameter block exceeds MODEL_PARAMS_LOAD_CAPACITY.

Run the filterbank NPU pipeline on the current input frame.

Executes the full filterbank feature extraction sequence:

  1. Computes NPU addressing parameters from the current input/output buffers.
  2. Iterates over MODEL_NUM_OUTPUT_BLOCKS output blocks.
  3. For each block: initializes max accumulators, loads MMR coefficients, programs common NPU state, loads instructions (block 0 only), and loads the block weight parameters.
  4. For each stride within the block: runs an MSB pass and an LSB pass via FBFE_RunTiniePass(), then updates the per-channel maximum values.
  5. Applies scale, offset, shift, and uint8_t quantization to each channel.
  6. Appends the resulting feature vector to the sliding NN input window.
Parameters
[in,out]ctxPointer to the initialized context.
Returns
true if the frame was processed successfully, false if ctx is NULL or uninitialized, or if a parameter block exceeds MODEL_PARAMS_LOAD_CAPACITY.
