Detailed Description

Configuration parameters for the filterbank feature extraction.

Populate this structure before calling FBFE_Init(). The entire structure is copied into the context during initialization, so the caller does not need to keep it alive afterwards.

The bit-manipulation fields (ls_mask, ms_mask, ms_shift, branch_bits) must be consistent with the model's expected input encoding. Incorrect values will produce silently wrong feature vectors.

§ sampling_rate_hz

uint32_t FBFE_Config::sampling_rate_hz

Input sampling rate in Hz.

Defines the sampling frequency of the incoming PCM audio stream (e.g., 16000 for 16 kHz). Used to derive frame and context lengths in samples from the millisecond-based window parameters.

§ window_size_ms

uint16_t FBFE_Config::window_size_ms

Processing window size in milliseconds.

Duration of each analysis frame. Together with sampling_rate_hz this determines NUM_SAMPLES (the number of PCM samples consumed per call to FBFE_RunOneFrame()).

§ context_ms

uint16_t FBFE_Config::context_ms

Temporal context size in milliseconds.

Amount of past audio retained between consecutive frames to provide temporal context for the neural network. Controls the overlap region copied at each frame boundary inside the NPU input buffer.

§ ms_mask

uint16_t FBFE_Config::ms_mask

Bitmask for extracting the most-significant byte of a sample.

Applied to the uint16_t view of the scaled sample to isolate the high-order bits before they are right-shifted by ms_shift and packed into ms_bytes[].

Referenced by FBFE_StoreSampleBytes().

§ ms_shift

uint8_t FBFE_Config::ms_shift

Right-shift amount applied after masking the MSB portion.

After ms_mask isolates the high-order bits, this shift aligns them to the least-significant position of the staging byte stored in ms_bytes[].

Referenced by FBFE_StoreSampleBytes().

§ branch_bits

uint8_t FBFE_Config::branch_bits

Effective branch bit-width for input sample scaling.

Controls how much the raw 16-bit PCM sample is scaled down before it is split into MSB/LSB bytes for NPU packing. The scaling is:

scale_shift = 16 - branch_bits
scaled = round(sample / 2^scale_shift)

Valid range is 1–16. A value of 16 disables scaling entirely.

Referenced by FBFE_PushSample().
